# Lexicon-norm scoresheet

*91 names. Listen to each name's takes in* `out/index.html`*, then tick the method(s) that came out **correct AND stable across the seeds**.*

**Navigate:** `Ctrl+Shift+O` (Go to Symbol) then type a name to jump; or use the Outline panel. **Mark:** toggle `[ ]`→`[x]` (keyboard), `Alt+C` with the *Markdown All in One* extension, or click the box in the Markdown preview.

Rules:

- Tick **as-written** ⇒ the name needs **no lexicon entry** (Chatterbox nails it unaided).
- Tick **more than one** if several work; leave **all blank** + add a note if none do.
- Single-syllable-per-word names (e.g. *Sun Tzu*) render **A and C identically** — expected.

Method legend — **as-written** = the raw name, no lexicon (does Chatterbox nail it unaided?); **A plain-hyphen** = capitalized, hyphens, no stress mark; **B stress-caps** = A + stressed syllable in ALL-CAPS; **C spaced** = A but spaces instead of hyphens.

> Generated by `build.py`; it will NOT overwrite this file once it exists, so your
> marks are safe across regenerations. Delete it to regenerate a blank sheet.
